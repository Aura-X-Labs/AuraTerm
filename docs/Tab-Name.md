# Tab Name

## Behavior

- New sessions use the bookmark name as the initial tab title when the session is saved.
- Opening the same named session multiple times adds a NATO suffix like `alpha`, `bravo`, and then numeric suffixes when needed.
- You can rename any open tab from the tab's right-click menu. This only changes the current tab title and does not overwrite the saved bookmark name.

## Notes

- Bookmark connections still use the bookmark name as the default tab title.
- Local shell tabs keep the default `Local Shell` title until they are renamed manually.
