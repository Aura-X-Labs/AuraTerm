# AuraTerm 功能列表

AuraTerm 是一款强大的终端模拟器，支持 SSH、Telnet、Serial 和本地 Shell 会话。

---

## 一、会话管理

### 1.1 多协议支持

| 协议 | 说明 |
|------|------|
| **Local Shell** | 本地终端，支持自定义 Shell 路径（Git Bash、PowerShell、CMD、自定义） |
| **SSH** | SSH 远程连接，支持密码认证和私钥认证 |
| **Telnet** | Telnet 远程连接 |
| **Serial** | 串口连接，支持完整串口参数配置 |

### 1.2 多标签页

- 创建、关闭、切换标签页
- 标签页拖拽排序
- 右键重命名标签页
- 自动生成唯一标签页标题（NATO 字母后缀）

### 1.3 会话日志

- 自动保存会话输出到日志文件
- 自定义日志保存路径
- 日志文件名模板支持占位符：
  - 时间：`{timestamp}`, `{datetime}`, `{date}`, `{time}`, `{yyyy}`, `{MM}`, `{dd}`, `{HH}`, `{mm}`, `{ss}`, `{unix}`
  - 会话：`{session}`, `{protocol}`, `{host}`, `{user}`, `{port}`, `{serialPort}`, `{baudRate}`

---

## 二、SSH 功能

### 2.1 认证方式

- **密码认证**：用户名 + 密码
- **私钥认证**：支持选择私钥文件，可选密钥密码

### 2.2 重连模式

| 模式 | 说明 |
|------|------|
| **Manual** | 手动重连，断开后按 `R` 键重连 |
| **Simple** | 简单自动重连，无需服务端工具 |
| **tmux** | 使用 tmux 保持会话，支持会话持久化 |
| **screen** | 使用 screen 保持会话，仅管理 `at-` 前缀的会话 |

### 2.3 MFA 支持

- 支持 SSH 多因素认证（交互式提示）

---

## 三、串口功能

### 3.1 串口配置

| 参数 | 选项 |
|------|------|
| 串口 | 自动枚举可用串口设备 |
| 波特率 | 自定义数值 |
| 数据位 | 5 / 6 / 7 / 8 |
| 停止位 | 1 / 2 |
| 校验位 | None / Odd / Even |
| 流控制 | None / Hardware / Software |

### 3.2 预设配置

- 内置常用预设：115200-8N1、9600-8N1、57600-8N1 等
- 自动记忆最近使用的串口配置
- 连接状态指示器（connecting / connected / closed / error）

---

## 四、书签管理

### 4.1 连接保存

- 保存连接配置到书签
- 支持分组管理
- 快速连接已保存的书签

### 4.2 书签操作

- 新增、编辑、删除书签
- 分组折叠/展开
- 搜索过滤书签

---

## 五、远程文件管理（SFTP/SCP）

> 仅 SSH 会话可用

### 5.1 文件浏览

- 浏览远程目录
- 面包屑导航
- 文件大小、权限、修改时间显示

### 5.2 文件传输

| 功能 | 说明 |
|------|------|
| **下载** | 从远程服务器下载文件到本地 |
| **上传** | 从本地上传文件到远程服务器 |
| **新建文件夹** | 在远程服务器创建目录 |
| **删除** | 删除远程文件或目录 |
| **传输模式** | SFTP 或 SCP |

### 5.3 传输状态

- 实时进度显示
- 传输完成/失败提示

---

## 六、输入工具栏

### 6.1 快捷按钮

- 自定义快捷命令按钮
- 按钮排序、编辑、删除
- 一键发送预设命令

### 6.2 输入框

- 多行文本输入
- 拖拽调整高度
- 双击折叠/展开
- `Ctrl+Enter` 发送

### 6.3 历史记录

- 自动保存发送过的命令
- `PageUp` 向上翻页（更早的历史）
- `PageDown` 向下翻页（更新的历史）
- 最多保存 100 条历史记录
- 自动去重

---

## 七、终端功能

### 7.1 显示设置

- 字体大小（8-72）
- 字体家族
- 回滚缓冲区行数

### 7.2 主题配置

- 背景颜色
- 前景颜色
- 光标颜色

### 7.3 键盘鼠标

| 功能 | 快捷键/操作 |
|------|-------------|
| 复制选中内容 | 选中时自动复制（可配置） |
| 粘贴 | `Ctrl+V` 或鼠标中键（可配置） |
| 放大字体 | `Ctrl++` |
| 缩小字体 | `Ctrl+-` |
| 重置字体 | `Ctrl+0` |
| 全屏切换 | `F11` |

- About AuraTerm

## 九、系统集成

### 9.1 Windows 资源管理器集成

- 右键菜单 "在 AuraTerm 中打开"
- 支持文件夹和文件夹背景右键
- 自动切换到指定目录

### 9.2 窗口状态持久化

- 保存窗口位置和大小
- 启动时恢复上次的窗口状态
- 自动适应显示器边界
